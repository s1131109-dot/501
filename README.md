# 記憶力翻牌大考驗 🃏

一個使用純 HTML + CSS + JavaScript 製作的記憶力配對翻牌遊戲。

## 功能介紹

### 核心玩法
- 點擊卡片將其翻開，配對兩個相同的 emoji 圖案
- 配對成功 → 卡片保持翻開並標示為綠色
- 配對失敗 → 卡片 0.8 秒後自動蓋回
- 所有卡片配對完成 → 顯示完成訊息（步數 & 花費時間）

### 三種難度
| 難度 | 棋盤大小 | 卡片對數 | Emoji 數量 |
|------|----------|----------|------------|
| 簡單 | 4 × 3 | 6 對 | 6 種 |
| 中等 | 4 × 4 | 8 對 | 8 種 |
| 困難 | 6 × 4 | 12 對 | 12 種 |

### 遊戲控制
- **難度選擇**：下拉選單切換三種難度
- **重新開始**：重置棋盤、步數與計時器

### 統計顯示
- **步數計數**：每次翻開兩張卡片計為一步
- **計時器**：從遊戲開始即時計秒

### 防護機制
- `isLock` 鎖定：配對判定期間禁止點擊其他卡片
- 已翻開 / 已配對的卡片無法再點擊
- 一次最多翻開兩張卡片

## 技術結構

```
memory-game.html (單一檔案，無外部依賴)
├── HTML         頁面結構、棋盤容器
├── CSS (內嵌)   卡片 3D 翻轉、版面配置、狀態樣式
└── JavaScript (內嵌)
    ├── shuffle()      Fisher-Yates 洗牌演算法
    ├── initGame()     初始化棋盤（依難度）
    ├── flipCard()     點擊翻牌邏輯
    └── checkMatch()   配對判定與狀態更新
```

### 使用技術
- **CSS 3D Transform**：`rotateY(180deg)` + `perspective` 實現翻牌動畫
- **Fisher-Yates 洗牌**：保證隨機公平性
- **純前端**：無需後端或第三方套件，開瀏覽器即可玩

## 使用方式

直接在任何現代瀏覽器中開啟 `memory-game.html` 即可開始遊戲。

也可透過 GitHub Pages 部署或直接下載到本機執行。
